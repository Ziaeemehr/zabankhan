# Study Activity and Manual Study Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add manual study logging with language-scoped sources and skills, and combine logged time with automatic app activity in accessible monthly/yearly heatmaps.

**Architecture:** Reuse the existing Room `StudySession`, `StudySource`, `StudyLogDao`, and schema version 5. Add commonMain aggregation and state for manual sessions, integrate the combined daily totals in the existing Progress screen, and add common Compose routes for the session list, entry form, and source manager. Keep source/skill summaries limited and use shared localized resources instead of French-specific assumptions.

**Tech Stack:** Kotlin Multiplatform, Compose Multiplatform, Room KMP, kotlinx-datetime, Compose Resources, commonTest.

**Spec:** [docs/superpowers/specs/2026-11-08-study-log-design.md](../specs/2026-11-08-study-log-design.md)

## Global Constraints

- Preserve Room schema version 5 and existing backup/restore/FrenchReader import contracts unless source inspection proves a schema change is necessary.
- Scope every study-session/source query and statistic to `settings.learningLang`.
- Common code must not use `java.*`, `android.*`, `org.json`, or Kotlin/Native-unsupported regex classes `\p{M}`/`\p{N}`.
- Use kotlinx-datetime for calendar-day calculations; do not add chart or date dependencies.
- Show combined manual and automatic time while keeping their components separately visible in day details.
- Support French and English learning data, English/French/Persian UI resources, RTL content behavior, and wrapping option layouts; do not add horizontally scrolling chip/menu rows.
- Do not touch FrenchReaderSpike files; use it as a read-only reference.
- Run the required verification gate with JDK 17 after implementation. Do not commit.

## Review Focus

- App activity and manual session overlap is included in the combined total; selected-day detail must preserve both inputs so the overlap is understandable. Pin with a combined-total/component-breakdown test.
- Switching the learning language must never mix sessions or sources between languages. Pin with a language-isolation aggregation/repository test.
- Month/year grids must handle leap years, first-day-of-week alignment, future days, and dates at the edges of the requested period. Pin with month/year boundary tests.
- Manual entries must reject invalid duration and future dates and preserve referenced historical sources when a source is archived. Pin with validation/source-lifecycle tests.
- Automatic activity is already persisted as local ISO dates and manual sessions as epoch days; combining these values must respect those persisted local calendar days without reparsing timestamps. Pin with an ISO-date-to-epoch-day aggregation test.
